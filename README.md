# 📸 EJS Instagram Mini Project

A beginner-friendly Instagram-style web page built using **Node.js, Express.js, EJS, and CSS**.

## 🚀 Features

- Dynamic user profile
- Followers and following count
- Dynamic posts using EJS
- EJS loops and conditional rendering
- Reusable navbar and footer using EJS includes
- Express static files
- Responsive and clean CSS design

## 🛠️ Technologies Used

- Node.js
- Express.js
- EJS
- HTML
- CSS
